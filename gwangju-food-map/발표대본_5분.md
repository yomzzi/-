## ② 1일차 · 0:30 ~ 2:10

`[H]` 첫날은 4.2km, 약 6천 보를 걸어요. / 11시 반, 문화전당역 근처 **호텔 리베로**에 배낭부터 맡기고 가볍게 출발합니다. //

`[1]` 첫 끼는 **행복담 크림순대국밥**, 13,000원이에요. / 순대국에 크림이라니 이상하죠? / 💬 그런데 생생정보에도 나온 집이래요. //

`[2]` 밥 먹고 **5·18민주광장이랑 옛 전남도청**을 걸어요. 스탬프 투어도 있어요. /
💬 여기서 TMI! / 민주광장 시계탑은 매일 **오후 5시 18분**에 '임을 위한 행진곡'을 들려준대요. //

`[3]` 2시 반엔 **ACC 한 바퀴 투어**를 하고, / 4시엔 미디어파사드도 봐요. /
💬 ACC 건물은 대부분이 **땅속에 숨어 있대요.** / 지붕 위 하늘마당은 무료 쉼터라 잠깐 쉬어 가기 좋아요. //

`[4·5]` 오후엔 동명동 카페거리로 넘어가요. / **티소하**에서 우지 말차 라떼 한 잔 마시고, / **창억떡집**에서 호박인절미를 포장해요. / 💬 SNS에서 핫해서 오픈런한다는 후기도 있대요. //

`[6]` 저녁은 **미미원 육전!** / 💬 육전은 '광주 7미' 중 하나고, 눈앞에서 바로 부쳐 줘요. //

`[7]` 7시 반엔 전일빌딩 옥상, **전일마루**에서 무료 야경을 보고, /
`[8]` 마지막은 **진스통 상추튀김**으로 마무리합니다. / 💬 상추튀김은 1975년쯤 충장로 튀김집에서 시작됐다는 설이 있어요. / 광주 왔으면 꼭 먹어 봐야죠!

## ③ 2일차 · 2:10 ~ 3:25

둘째 날은 더 가볍게, / 2.9km, 약 4천 보예요. /

`[9]` 먼저 **궁전제과**에서 공룡알빵이랑 나비파이를 사요. / 늦으면 매진이라 아침 일찍 가야 해요. //

`[7]` 그다음 **전일빌딩 10층** 전시를 보고, 11시 해설을 들어요. /
💬 이름 속 245는 건물에 남은 **탄흔 245개**래요. / 주소도 금남로 245고요. //

`[10]` 이어서 **5·18민주화운동기록관**에 가요. / 💬 5·18 기록물은 2011년에 **유네스코 세계기록유산**이 됐대요. //

`[11·12]` 그리고 **예술의 거리**에서 갤러리랑 골동품을 구경하고, / **광주극장**까지 걸어요. /
💬 광주극장은 1935년에 문을 연 단관극장인데, / 영화 간판을 아직도 손으로 그린대요. //

`[13]` 점심은 **평화식당 애호박찌개!** / 💬 24시간 문을 여는 50년 노포고, / KIA 선수들도 온다는 소문이 있어요. //

2시 반에 짐 찾고, / 문화전당역에서 안녕!

## ④ 걷기 · 숙소 · 경비 · 3:25 ~ 4:05

`[하단 카드]` 이렇게 많이 걸어도 될까 싶으시죠? / 그래도 제일 긴 구간이 미미원에서 전일빌딩까지 **14분**이라, 배낭 메고도 괜찮아요. //

숙소는 **호텔 리베로**예요. / 평점 9.6에 73,000원이고, / 문화전당역 3번 출구에서 걸어서 3분, 동선 딱 한가운데예요. / 걸어서 오는 손님은 짐 보관도 해 줘요. //

경비는 두 명 기준 **한 사람당 약 12만 원**이에요. / 숙소, 밥 네 끼, 카페, 포장 간식까지 다 포함이고, / 교통비는 따로예요.

- **시간이 모자랄 때 뺄 문장** (모두 빼면 약 15초 단축)
  - 1일차: "스탬프 투어도 있어요", "광주 왔으면 꼭 먹어 봐야죠!"
  - 2일차: "예술의 거리에서 갤러리랑 골동품을 구경하고"

- **예상 질문**
  - 비 오면? → ACC, 전일빌딩, 기록관이 실내라서 비 오는 날 동선으로 바꿀 수 있어요.
